# Freitags Fix Agent brand

A little repair bot in Freitags colors with a tool belt (wrench and screwdriver). It eats a pizza slice, pulls the wrench from its belt, "fixes" the bitten slice with sparkles, then holsters the wrench. The loop is 5 s.

| File | What |
|---|---|
| `fix-agent-bot.js` | The animated mascot as SVG, driven by time so videos can render it frame by frame: `FixBot.create(svg, id).render(seconds)` |
| `preview.html` | Live preview: mascot, logo lockup, transition card with the faint mascot behind the text |
| `fix-agent-bot.gif` / `.png` | Mascot loop / still |
| `fix-agent-lockup.png` | Mascot + "Freitags Fix Agent" + "Keeps every small business taking orders" |
| `transition-card-preview.gif` | How the transition cards in the demo video use it |

Colors: red `#c8102e`, amber `#e9b45f`, cream `#f6efe3`, ink `#2b1d14`, background `#17120f`. Wordmark font: DejaVu Serif, bold.
